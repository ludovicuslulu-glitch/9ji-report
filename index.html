二、九机业务复盘

2.1 分期免息价差分析

💰 双价展示铁证：标准版¥11,249 vs 免息分期版¥12,799 = 溢价¥550（4.9%）。用户选分期时价格自动上浮，覆盖手续费后商家仍有利润。这就是「提价免息」模式的落地形态。

2.2 分期利益点表达 核心差异

🔑 决策前置 vs 决策滞后：九机在浏览阶段植入分期认知，转转在支付阶段才告知——差了整个决策流程。
建议：转转在商品列表页增加「可分期」「月供¥XXX」轻量级标签。

2.3 收银台合规设计

九机收银台三个行为特征：① 默认选中分期 → 降低决策成本；② 底部按钮即分期名称 → 强化分期心智；③ 未分区但意图明确 → 分期成为"自然选择"。详细截图见「一、1.7」。

三-2. 线下部分

1）服务温度 & 连带销售 NEW

维度九机转转
进店体验☕ 温茶招待，建立好感❄️ 全自助，无接待
选购过程店员走开、不打扰自行选购
结账触发用户召唤店员到身边自行扫机器背后二维码
推销节点结账时三合一推销（配件+权益+分期）无推销节点
连带销售赠品延保 + 盾牌套餐（见上图）❌ 无
店员角色主动服务者不参与
九机流程： 进店 → ☕ 温茶 → 店员离开（不打扰）→ 用户召唤结账 → 🤝 推销配件+权益+分期 → Pad支付
转转流程： 进店 → 自行选购 → 扫码 → 小程序支付 → 全程无店员互动
🔑 差距本质：九机把结账变成销售机会（配件+权益+分期三合一），转转把结账变成纯工具操作。差的不只是服务态度，是整个收入模型。

2）支付体系 NEW

维度转转门店九机门店
支付工具用户自己手机店员手持Pad
支付方式仅扫码/APP支付刷卡 + 主动扫码 + 被扫
分期支持❌ 不支持✅ 支持分期 + 免息
收银台二维码即收银台无固定收银台，Pad即收银台
会员识别无扫会员码 → 识别身份 + 积分
店员参与不参与全程参与，主动推销
🔑 核心差距：转转门店=展示场所，支付走线上；九机门店=支付场景。转转门店不支持分期 = 完全放弃最大金融转化点。
