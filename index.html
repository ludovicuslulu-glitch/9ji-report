四、业务经验交流（线下部分）⭐

4.1 服务温度

🤝 九机（有温度）

进店 → ☕ 温茶 → 不打扰选购 → 用户召唤店员 → 🤝 推销配件+权益+分期 → 📱 Pad支付（含分期/免息）

🧍 转转（零温度）

进店 → 自助选购 → 扫码 → 小程序支付 → ❌ 店员不参与推销
维度九机转转
进店☕ 温茶❄️ 无接待
结账用户召唤 → 集中推销自行扫码 → 无推销
店员主动服务者不参与
🔑 九机把结账变成销售机会（配件+权益+分期佣金），转转把结账变成纯工具操作。

4.2 支付体系

🧍 转转门店

❌ 仅扫码/APP支付
❌ 不支持分期
❌ 不支持免息
❌ 无店员介入

🤝 九机门店

✅ 刷卡 + 扫码 + 被扫
✅ 支持分期 + 免息
✅ Pad随人走，无固定收银台
✅ 扫会员码识别身份
🔑 转转门店不支持分期，等于把最大的金融转化点完全放弃。

4.3 门店销售品类

九机（综合店 — 7大品类）转转（单一店 — 1-2品类）
✅ 二手良品 / 配件专区 / 母婴 / 手机 / 平板 / 笔记本 / 摄影摄像 / 手表✅ 二手3C数码 / ❌ 无独立配件区 / ❌ 无其他品类
🔑 九机「2元配件」引流 → 建立首次支付 → 高价分期转化。多品类 = 更多支付触点 = 分期渗透率提升空间更大。
