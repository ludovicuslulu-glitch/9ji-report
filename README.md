```
进店 → ☕热饮招待 → 🏃自由体验真机 → 🤝店员手持Pad走到你身边
```

## 三、业务经验交流（线上部分）

### 3.1 分期提价做免息

| 维度 | 转转 | 九机 |
|------|------|------|
| 分期展示 | 支付环节才出现 | **商品页即展示月供** |
| 定价方式 | 单一价格 | **双价展示**：免息价 vs 全款价 |
| 免息成本 | 平台补贴 | **提价免息**（涨价覆盖成本） |
| 价差透明度 | 用户看不到分期成本 | 双价并排，用户可比较 |
| 实际溢价 | 无（平台兜底） | ~8.5%（覆盖手续费+额外利润） |
| 利润空间 | 平台承担成本 | 商家覆盖成本+额外利润 |
| 可持续性 | 需持续投入补贴 | 商家有自驱力推分期 |

> **结论**：九机模式更可持续——商家有利润就有动力主动推荐分期。

## 四、业务经验交流（线下部分）⭐ 新增

### 4.1 服务温度

#### 九机服务流程

```
进店 → ☕店员递上一杯温茶 → 店员走开，不打扰选购 → 用户自由体验
                                                    ↓
                        结账环节：用户召唤店员到身边
                                                    ↓
              🤝 店员推销：配件增购 + 权益产品 + 引导分期服务
                                                    ↓
                              📱 手持Pad完成支付（含分期/免息）
```

**九机的「温度哲学」：**
- 🍵 **先给温度，再给空间** — 一杯温茶建立好感，然后走开让用户自由逛
- 🎯 **用户召唤 = 最佳推销窗口** — 用户主动找你结账时，推荐接受度最高
- 📦 **结账环节 = 连带销售黄金点** — 配件 + 权益 + 分期三合一推销

#### 转转服务流程

```
进店 → 全是"I人"（自助氛围）→ 自行选购 → 自行扫机器背后二维码
                                                    ↓
                                          小程序内自助支付
                                                    ↓
                                        店员不参与推销服务
```

**转转的「自助困境」：**
- ❄️ **全程自助、零温度** — 无招待、无引导、无推销
- 📱 **扫码支付 = 隔绝了人与人的接触** — 店员连"你好"的机会都没有
- 🚫 **主动引导销售机会完全缺失** — 配件、权益、分期无人推销

#### 对比总结

| 维度 | 九机 | 转转 |
|------|------|------|
| 进店体验 | ☕ 温茶招待，建立好感 | ❄️ 全自助，无接待 |
| 选购过程 | 店员走开、不打扰 | 自行选购 |
| 结账触发 | 用户召唤店员到身边 | 自行扫码 |
| 推销节点 | 结账时集中推销（配件+权益+分期） | **无推销节点** |
| 店员角色 | 主动服务者 | 不参与 |
| 温度感受 | 🔥 有人情味 | ❄️ 冷冰冰 |

> **🔑 核心洞察**：九机把结账环节变成了**销售机会**，转转把结账环节变成了**纯工具操作**。差的不只是服务态度，是整个收入模型——九机每笔交易能多赚：配件利润 + 权益收入 + 分期佣金。

### 4.2 支付体系

#### 转转门店支付体系

```
┌──────────────────────────────────────┐
│  转转门店支付方式                      │
│                                       │
│  仅支持：                              │
│  📱 扫机器背后二维码 → 小程序支付       │
│  📱 APP内支付                          │
│                                       │
│  ❌ 不支持分期支付                      │
│  ❌ 不支持免息支付                      │
│  ❌ 无店员介入支付流程                   │
└──────────────────────────────────────┘
```

**转转门店支付 = 纯线上自助**，门店仅提供商品展示和二维码入口。

#### 九机门店支付体系

```
┌──────────────────────────────────────────────┐
│  九机门店支付方式                              │
│                                               │
│  流程：店员手持Pad → 绑定机器                  │
│        → 扫用户会员码（识别身份+积分）          │
│                                               │
│  用户可选择：                                  │
│  💳 刷卡支付                                   │
│  📱 主动扫码支付                               │
│  📱 被扫服务（店员扫用户付款码）                 │
│                                               │
│  ✅ 支持分期支付                               │
│  ✅ 支持免息支付                               │
│                                               │
│  🏗️ 去掉了固定收银台                           │
│  👨‍💼 提升了店员主动销售机会                      │
└──────────────────────────────────────────────┘
```

#### 关键差异

| 维度 | 转转门店 | 九机门店 |
|------|---------|---------|
| 支付工具 | 用户自己的手机 | **店员手持Pad** |
| 支付方式 | 仅扫码/APP支付 | **刷卡 + 主动扫码 + 被扫** |
| 分期支持 | ❌ **不支持** | ✅ **支持分期 + 免息** |
| 收银台 | 有固定收银概念（二维码即收银台） | **无固定收银台，Pad即收银台** |
| 会员识别 | 无 | 扫会员码 → 识别身份 + 积分 |
| 店员参与 | 不参与 | 全程参与，主动推销 |
| 销售机会 | 无 | **结账 = 销售机会** |

> **🔑 核心洞察**：
> 1. 转转门店**门店≠支付场景**，门店只是展示，支付走线上路径
> 2. 九机门店**门店=支付场景**，Pad移动支付打通了线下分期
> 3. 转转门店不支持分期，等于把最大的金融转化点**完全放弃**
> 4. 九机去掉固定收银台 → 店员走到哪卖到哪 → **支付不设限，销售无死角**

### 4.3 门店销售品类

#### 品类结构对比

| 九机（综合店） | 转转（单一店） |
|------|------|
| ✅ 二手良品 | ✅ 二手3C数码 |
| ✅ 配件专区（壳/线/耳机/充电宝） | ❌ 无独立配件区 |
| ✅ 母婴专区 | ❌ 无 |
| ✅ 手机专区 | — |
| ✅ 平板专区 | — |
| ✅ 笔记本专区 | — |
| ✅ 摄影摄像专区 | — |
| ✅ 手表专区 | — |
| — | ❌ 品类单一 |

#### 关键差异

| 维度 | 九机 | 转转 |
|------|------|------|
| 店型 | **综合店** | 单一品类店 |
| 品类数量 | 7大品类线 | 1-2个（二手3C为主） |
| 客单价跨度 | **2元配件 ~ 万元旗舰机** | 集中在2,000-4,000元 |
| 单店利用率 | **高**（多品类共享流量） | 低（品类单一、流量浪费） |
| 引流能力 | **强**（配件/母婴低价引流） | 弱（仅二手3C） |
| 连带销售 | **强**（配件+手机+权益） | 弱（品类少，难以连带） |

> **🔑 核心洞察**：
> 1. 九机做**宽**（全品类覆盖、流量复用），转转做**深**（二手3C专精）
> 2. 九机的「2元配件」是引流利器 → 建立首次支付 → 后续高价分期转化
> 3. 转转品类单一意味着：**流量利用效率低**、**连带销售空间小**、**分期场景受限**
> 4. 多品类 = 更多支付触点 = **分期渗透率提升空间更大**
