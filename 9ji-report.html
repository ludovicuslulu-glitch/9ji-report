九机业务分期复盘&业务经验交流

核心判断

  • 分期本质是价格转译工具：九机不是把分期当支付方式，而是把分期做成高客单二手零售的成交基础设施：用月供降低价格压力，用免息提高成交确定性，所以分期 GMV 渗透率能到 29.4%。
  • 九机门店服务更有温度：九机进店先做轻接待，再给用户自由逛店空间，形成更自然的零售场景。转转门店更偏明确需求履约，后续可学习九机在进店引导和现场陪伴上的服务颗粒度。
  • 九机在免息商品上更主动：九机已在分期维度主动尝试"提价做免息"，用分期版价格覆盖手续费，同时保留商家利润空间。相比之下，转转当前更多停留在现有支付能力承接，先发性和商品化表达仍需加强。

2.4 转转门店分期交易链路 vs 九机

九机门店交易链路

  1. 用户进门
  2. 自由逛店/体验样机
  3. 店员现场陪伴
  4. 收银台（含分期）
  5. 用户提货

转转门店交易链路

  1. 用户进门
  2. 沟通需求
  3. 展示商品
  4. 收银（无分期）
  5. 用户提货

⚠️ 关键差距：转转门店收银台不支持分期支付，九机门店收银台已接入分期。转转门店的高客单商品（¥3,000+手机）在成交环节没有分期承接，可能导致一定比例的丢单。

三、转转分期提升建议 & 行动计划

3.1 整体战略方向

方向 说明
把分期从"支付方式"升级为"成交工具" 不是在收银台等用户选，而是在浏览、逛店阶段就植入"月供¥XXX"的心智
线上先做轻标签，再做重入口 列表页加"可分期"标签成本低、见效快，比大改商品详情页更先落地
门店做分期"引导页"而非完整收银 店员引导用户扫码进入分期流程页面，不需要改造收银系统

3.2 分阶段动作（P0/P1/P2）

优先级 动作 验证指标 负责方
P0 转转APP商品列表页增加"可分期""月供¥XXX"标签 分期入口点击率提升 30%+ 产品 + 前端
P0 转转门店增加分期引导物料（扫码进入分期流程） 门店分期订单占比从 0 提升至 5%+ 运营 + 门店
P1 接入工行分期等低费率银行直连渠道 12期商贴费率从 3.75% 降至 3.5% 以下 商务 + 金融
P1 商品维度设计"提价做免息"方案 免息商品边际利润覆盖手续费成本 产品 + 金融
P2 转转门店收银系统接入分期支付 门店分期渗透率达 10%+ 产品 + 技术
